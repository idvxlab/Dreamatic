# Static HTML expression

Translate the approved exhibition direction into inspectable source. The owning
professional method determines the design; exhibition storytelling determines the
argument and sequence. This method supplies semantic and responsive expression,
not a new design thesis, file-writing permission or an execution protocol.

## Express the hierarchy

Use meaningful headings, figures and captions. Keep essential explanations in
selectable text beside the relevant work. Native links and anchors can support
navigation and access to full images without a script-dependent interface.
A static exhibition of interface concepts does not implement their intended flows.

Use the available source format and asset references exactly as supplied by the
host. Do not invent resource paths, split the deliverable into extra files, add
scripts or install dependencies merely because HTML could support them.
File organization, persistence and the final response format belong to the host.

## Preserve the work across sizes

Fit images without distortion and retain a complete view when inspection matters.
Let grid/flex children shrink, allow long text and links to wrap, and select column
counts from content and reading order rather than a universal page template.
On narrow screens retain work visibility, narrative order and access to details.
Use available fonts, sufficient contrast, semantic labels and visible keyboard focus.

Do not hide required material behind scripted controls or reveal effects. A control
must have a meaningful implemented action; static presentation does not justify
fake buttons, forms, metrics or application states.

## Carry evidence faithfully

Keep the identities of works, assets and sources stable. Preserve citation numbers
already assigned by the host or supplied research. If no numbering exists, follow
the requested citation convention consistently. Link each citation to the matching
source and show only references actually adopted by the presented argument.

Retain verified titles, authors and bibliographic facts; mark uncertainty instead
of inventing missing metadata. Use a readable secondary references area when
sources were used. An original proposal does not need a fabricated bibliography.

## Check the actual expression

Check image references, full-work visibility, heading order, text wrapping and
readability against the available sources. Inspect the rendered page only when a
preview capability is available; distinguish source inspection from browser testing.
Record limitations honestly. Source validity alone does not establish visual quality,
accessibility conformance or implemented product behavior.
