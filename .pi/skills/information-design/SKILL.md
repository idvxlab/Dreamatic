# Information and Data Visualization Design

Use this independent knowledge module to inform the canonical Design Spec.
Select the dimensions relevant to the brief; the Agent contract governs tools,
output formats, image-size ceilings and stage completion.

## Reader question and evidence
Define the question, audience, context and intended comparison. Identify source,
units, time period, categories, denominators, missing values and uncertainty.
Separate measured data, derived values, examples and speculation.

Choose representation from the relationship: comparison, trend, distribution,
part-to-whole, spatial pattern, process or network. Define visual encodings
explicitly so each mark and channel has a consistent meaning.

## Truthful communication

Explore representations by the reader's question and relationship, not decorative
chart variety. Compare direct comparison, sequence, spatial mapping or layered
explanation only where each preserves the same evidence. Test what a reader
can infer from scale, ordering and emphasis; novel metaphor must not distort data.
For the chosen encoding, specify data dependencies, geometry and annotations
and identify the misunderstood comparison it must avoid. Compare comprehension
and production/maintenance complexity; flag missing data rather than filling
an attractive template with invented values.
Use baselines, scale and ordering that make the intended comparison interpretable.
Explain truncation, normalization and aggregation where used. Distinguish
correlation from causal explanation. Preserve uncertainty rather than drawing
unwarranted precision from incomplete evidence.

Define labels, units, legends, annotations and reading order. Consider
color-independent differentiation, text alternatives and dense-data readability.
Simplify without removing context necessary to interpret the claim.

## Delivery planning
Specify chart or diagram geometry, encoding rules, exact data and copy in the
Design Spec and in each relevant image prompt. Generation can integrate titles,
labels, legends and annotations into the graphic; do not omit those elements or
replace them with gallery-only explanations. Preserve supplied data and avoid
invented values. For exact quantitative geometry, use an appropriate approved
implementation method and distinguish illustrative rendering from verified data
accuracy. Text generation itself does not require an extra compositor.

Select overview and detail views according to distinct reader questions.
Include supporting comparisons when needed to explain a finding, without a
fixed image count.

## Quality judgment
The result should answer the reader's question without misleading inference.
An attractive infographic is insufficient when its numbers, relationships or
uncertainty are ambiguous. Record unsupported data needs as gaps, not invented
facts.
