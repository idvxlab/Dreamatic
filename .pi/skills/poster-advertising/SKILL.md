# Poster and Advertising

Use this optional module for posters, key visuals, campaign systems, launch graphics, and advertising concepts.

## Communication Frame

Clarify before styling:

- audience, communication goal, desired response, and viewing context;
- primary message, supporting information, and mandatory content;
- cultural context, tone, emotional promise, and potential sensitivities;
- visual hook, mnemonic device, and reason the concept is ownable;
- required formats, placements, reading distance, and time available to understand it.

## Concept Development

Explore alternative persuasive mechanisms before style: a meaningful demonstration,
contrast, metaphor, narrative or unexpected juxtaposition when appropriate.
Each direction needs a clear connection between audience insight and response.
Recombine rhetorical and compositional principles rather than copy a campaign's
distinctive layout. Compare alternatives using the same message, placement and
reading time; develop the selected visual hook, copy hierarchy and contextual
adaptations. Explain reproduction, imagery/copy dependencies and limits; do not
claim campaign effectiveness without audience evidence.

Build the proposal around one clear communication idea. Let imagery, typography, color, and composition reinforce that idea rather than compete for attention. Distinguish the campaign's transferable system from a single attractive layout.

Separate subject references from campaign precedents. Subject references
document the place, people, object or activity the message must communicate;
retain distinguishing features when recognition matters. Campaign precedents
can teach hierarchy, rhetoric, pacing and image treatment, but copying another
campaign's composition or distinctive device is not a new concept. Develop an
original communication treatment of the actual subject, not a generic substitute
chosen to avoid recognizability. State asset-specific usage evidence separately.

## Proposal Coverage

Build a coverage map from the campaign's messages, audiences, channels and use
contexts. Explore meaningful creative directions and present their differences,
then develop the applicable main posters, series, format adaptations, contextual
placements and detailed typography/graphic studies. A master visual plus one
adaptation is not a default complete set. Show enough distinct outcomes to
explain the campaign and its reasoning; there is no count ceiling unless the
user sets one or asks for fewer images. Avoid duplicates, not useful breadth.

For every generated image, define the message it must communicate, composition, text zones, imagery, color behavior, format, acceptance criteria, and output size. Use lower resolution for exploratory or supporting layouts.

Develop the headline, supporting copy, brand name and call to action appropriate
to the brief. Put their exact approved wording and typography/layout directions
into the generation prompt so the result is a complete poster, not a blank
background. Preserve critical wording in structured copy as well. Balance text
density and resolution for readability; acknowledge rendering uncertainty
without banning text or silently deferring all copy to a gallery caption.

## Quality Lens

Judge the proposal by message clarity, stopping power, hierarchy, distinctiveness, cultural fit, legibility, and adaptability. Expressive choices are welcome when they strengthen the intended response.
