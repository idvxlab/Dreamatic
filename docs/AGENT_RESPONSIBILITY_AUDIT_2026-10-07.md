## 职责界限说明

HTML 的现行实现是 Designer 写明确的 HTML/CSS/JS 源文件，Reviewer 审批后 Builder 调用 html_generate 复制/映射到交付路径。它满足 Builder 调用 HTML 工具生成文件，但工具不是让另一个模型根据抽象文字重新编码。这样的实现保留了审批前后源码一致性，避免 Builder 重新理解并改变方案；若要求 Builder 独立编码，则会改变当前设计与审批的边界，需要另行定义。

Builder 的文件存在性、路径安全、资源凭据、哈希和输出完整性检查属于执行所需的机械检查，不是二次设计审查，不应删除。输入缺失或提供商执行失败时仍需报告 Orchestrator，不能以“机械执行”为由伪造成功。

Designer 仍保留 user_asset_import，可以从已授权来源导入已选素材；本次未撤销这一既有复用路径。Researcher 应承担搜索、材料提取和原始素材准备，Designer 不具有搜索工具。若要求连授权素材的持久化导入都只能由 Researcher 执行，则这一权限也需要进一步收敛。
